Glioblastoma scRNA-seq - Integration of the Manual and Octo Samples

Glioblastoma FFPE Tissue Dissociated Manually or with the gentleMACS Octo Dissociator

Integration of the Manual and Octo samples

Analysis setup

The two glioblastoma samples originate from the same donor and FFPE specimen and were processed with the same probe panel, in the same GEM lane and with the same Cell Ranger version. The dissociation method (manual or gentleMACS Octo) is therefore the only experimental difference between them, and the samples behave as two technical replicates of the same tumour.

Integration is not always necessary. The samples were first processed jointly without integration. If the clusters separate cells by biology rather than by sample, integration is not required; if they separate cells by sample, the embeddings are aligned before the clustering is repeated. Several integration methods were then compared with metrics fixed in advance, and the unintegrated embedding was retained as a candidate. A difference in cell-type composition between the samples was documented before integration, because it may reflect the dissociation method and must not be removed by the correction.

Integration corrects the low-dimensional embedding used for the neighbour graph, the clustering and the UMAP. It does not modify the expression values: scores, differential expression and cell-cell communication are computed on the normalised expression of the RNA assay.

Utility functions

These functions summarise and visualise the distribution of the samples (or of the cell types) within clusters.

# Count the cells of each group in each cluster and compute their frequencies
summarize_clusters_by_group <- function(seurat_obj, cluster_column_name, batch_column_name) {
  seurat_obj[[]] %>%
    dplyr::count(
      cluster = .data[[cluster_column_name]],
      batch = .data[[batch_column_name]],
      name = "cell_count"
    ) %>%
    dplyr::group_by(cluster) %>%
    dplyr::mutate(freq = cell_count / sum(cell_count)) %>%
    dplyr::ungroup()
}

# Plot the number of cells per cluster, coloured by group
plot_cluster_sample <- function(cluster_summary_df, overall_title) {
  ggplot(cluster_summary_df, aes(x = cluster, y = cell_count, fill = batch)) +
    geom_bar(stat = "identity", position = "stack") +
    labs(x = "Cluster", y = "Number of cells", fill = "Group") +
    ggtitle(overall_title) +
    theme_minimal() +
    theme(plot.title = element_text(hjust = 0.5))
}

Clustering and batch assessment without integration

The clusters of the unintegrated embedding were examined with respect to the sample. The graph, the clusters and the UMAP of each embedding were computed by the same function, so that all methods are treated identically.

# Build the neighbour graph, the clusters and the UMAP of one embedding
cluster_embedding <- function(obj, reduction, tag, n_dims, res) {
  d <- 1:min(n_dims, ncol(Embeddings(obj, reduction)))
  graph_names <- paste0(tag, c("_nn", "_snn"))

  obj <- FindNeighbors(obj, reduction = reduction, dims = d,
                       graph.name = graph_names, verbose = FALSE)
  obj <- FindClusters(obj, graph.name = graph_names[2], resolution = res,
                      cluster.name = paste0("clusters_", tag), verbose = FALSE)
  obj <- RunUMAP(obj, reduction = reduction, dims = d,
                 reduction.name = paste0("umap_", tag),
                 reduction.key = paste0("UMAP", tag, "_"), verbose = FALSE)
  obj
}

Integration methods

Three integration approaches were applied to the principal-component embedding of the joint dataset, each producing a corrected low-dimensional embedding:

  • Harmony iteratively adjusts the position of the cells in the embedding with a soft clustering and a diversity penalty (theta); it was applied through the Seurat wrapper and through the standalone package.
  • RPCA aligns the samples with anchors found in reciprocal principal-component spaces, a conservative approach when populations are not fully shared.
  • CCA aligns the samples with anchors found in a canonical-correlation space, a stronger correction with a higher risk of over-correction.

Harmony was additionally run with three values of theta (1, 2 and 4) to document how the strength of the correction affects sample mixing and the conservation of the biology. All methods were run with their default parameters, on the same 20 principal components.

Evaluation of the integration

The methods were evaluated on two complementary criteria, computed on the same 20 dimensions and with the same labels.

Mixing of the samples (the correction should remove the technical difference):

  • iLISI is the inverse Simpson index of the sample composition among the 90 nearest neighbours of each cell. It was rescaled from 0 (neighbourhoods containing a single sample) to 1 (neighbourhoods containing both samples in equal proportions).
  • Cluster deviation is the mean absolute difference, weighted by cluster size, between the fraction of Octo cells in a cluster and the fraction of Octo cells in the whole dataset; 0 corresponds to a perfect mixing.

Conservation of the biology (the correction should not merge distinct cell types):

  • cLISI purity is the inverse Simpson index of the cell-type composition among the nearest neighbours, rescaled from 0 (neighbourhoods containing all the cell types) to 1 (neighbourhoods containing a single cell type).
  • ARI is the adjusted Rand index between the clusters and the Manual annotation, computed on the Manual cells only, which are the only cells carrying an annotation rather than a transferred label.
  • Silhouette is the mean silhouette width of the cell types, averaged over the cell types, on a random subset of 2,000 cells.

The LISI metrics were computed with a nearest-neighbour implementation with uniform weights, a simplified version of the original LISI that does not require an additional package.

# Inverse Simpson index of the label composition among the k nearest neighbours
knn_lisi <- function(embedding, labels, k = 90) {
  nn <- RANN::nn2(embedding, k = k + 1)$nn.idx[, -1, drop = FALSE]
  lab <- as.integer(factor(labels))
  n_lab <- max(lab)

  vapply(seq_len(nrow(nn)), function(i) {
    p <- tabulate(lab[nn[i, ]], nbins = n_lab) / k
    1 / sum(p^2)
  }, numeric(1))
}

# Adjusted Rand index between two partitions
adjusted_rand_index <- function(x, y) {
  tab <- table(x, y)
  n <- sum(tab)
  sum_comb <- function(v) sum(choose(v, 2))

  index <- sum_comb(tab)
  sum_rows <- sum_comb(rowSums(tab))
  sum_cols <- sum_comb(colSums(tab))
  expected <- sum_rows * sum_cols / choose(n, 2)

  (index - expected) / ((sum_rows + sum_cols) / 2 - expected)
}
# Define the cells used for the silhouette and the Manual cells used for the ARI
set.seed(the.seed)
silhouette_cells <- sample(ncol(sobj), min(2000, ncol(sobj)))
is_manual <- sobj$sample == "Manual"

n_samples <- length(unique(sobj$sample))

# Evaluate one embedding
evaluate_embedding <- function(obj, reduction, cluster_column, n_dims) {
  d <- 1:min(n_dims, ncol(Embeddings(obj, reduction)))
  emb <- Embeddings(obj, reduction)[, d, drop = FALSE]
  clusters <- obj@meta.data[[cluster_column]]

  # Mixing of the samples
  ilisi <- knn_lisi(emb, obj$sample, k = k_lisi)
  tab <- table(clusters, obj$sample)
  frac_octo <- tab[, "Octo"] / rowSums(tab)
  p_global <- mean(obj$sample == "Octo")
  cluster_deviation <- sum(rowSums(tab) * abs(frac_octo - p_global)) / sum(tab)

  # Conservation of the biology
  clisi <- knn_lisi(emb, obj$celltype, k = k_lisi)
  ari <- adjusted_rand_index(clusters[is_manual], obj$celltype[is_manual])
  lab_int <- as.integer(factor(obj$celltype[silhouette_cells]))
  sil <- silhouette(lab_int, dist(emb[silhouette_cells, , drop = FALSE]))
  sil_width <- mean(tapply(sil[, "sil_width"], lab_int, mean))

  data.frame(
    n_clusters = length(unique(clusters)),
    ilisi_norm = (mean(ilisi) - 1) / (n_samples - 1),
    cluster_deviation = cluster_deviation,
    clisi_purity = (n_labels - mean(clisi)) / (n_labels - 1),
    ari_manual = ari,
    silhouette = sil_width
  )
}

Selection of the embedding

The embedding was selected with the rule defined before the analysis. An integrated embedding was eligible if it conserved the biology, with a cLISI purity and an ARI within 0.05 of the unintegrated embedding, and if it improved the iLISI by at least 0.05. Among the eligible embeddings, the one with the highest iLISI was retained. If no integrated embedding was eligible, the unintegrated embedding was retained.

Scope and limits of the evaluation

This evaluation compares embeddings obtained from two technical replicates of the same specimen, so it measures the sensitivity of the analysis to the dissociation method and not to a difference between patients. The conservation metrics rely on the Manual annotation and on the labels transferred to the Octo cells; the independent annotation of the Octo cells with the marker panel of the Manual sample is performed in the comparison document, and the agreement between the two annotations is reported there. The silhouette was computed on a subset of 2,000 cells with a fixed seed.
