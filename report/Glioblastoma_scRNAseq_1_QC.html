Barcode-rank curve

The total number of UMIs was calculated for every barcode. Barcodes were then ranked from the highest to the lowest RNA content to generate a barcode-rank, or knee, plot.

# Calculate the total number of UMIs detected in each barcode
nb_umi_by_barcode <- data.frame(barcode = colnames(scmat),nb_umi = Matrix::colSums(scmat))

# Rank barcodes from the highest to the lowest UMI count
nb_umi_by_barcode <- nb_umi_by_barcode %>% arrange(desc(nb_umi)) %>%
  mutate(barcode_rank = seq_len(n()))

The curve displayed a broad transition in the range of a few thousand UMIs. Because the transition was not used as a strict automated cell-calling threshold, subsequent filtering was based on the observed gene, UMI and mitochondrial distributions.

As the raw matrix was used, the initial gene and UMI filters also acted as an empirical empty-droplet filter. A statistical method such as DropletUtils::emptyDrops() could be used as a complementary sensitivity analysis, but it was not used to define the primary dataset in this workflow.

No upper gene-count threshold was applied at this stage. Brain and tumour cells can exhibit high transcriptional complexity, and an arbitrary upper cut-off could remove genuine biological populations. Potential multiplets were evaluated later using scDblFinder.

Normalisation

The retained count matrix was normalised using Seurat’s LogNormalize method. For each cell, gene counts were divided by the total cellular count, multiplied by the default scale factor of 10,000 and log-transformed.

# Normalise gene expression while preserving the raw counts
sobjFiltrd <- NormalizeData(object = sobjFiltrd,normalization.method = "LogNormalize",
  scale.factor = 10000,verbose = FALSE)

Raw counts remained available in the counts layer, while the normalised expression values were stored in the data layer. We can also perform SCTransform, but this method does require some computational ressources since it uses GLMs to adjust residus
