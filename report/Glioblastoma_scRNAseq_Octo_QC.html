Glioblastoma scRNA-seq - Quality Control of the Octo-Dissociated Sample

Glioblastoma FFPE Tissue Dissociated with the gentleMACS Octo Dissociator, Multiplexed Samples

Quality Check of the data

Analysis setup

This document performs the quality control of the glioblastoma sample dissociated with the gentleMACS Octo Dissociator. The sample originates from the same donor and FFPE specimen as the manually dissociated sample, and was processed with the same probe panel, in the same GEM lane and with the same Cell Ranger version (7.1.0). The dissociation method is therefore the only experimental difference between the two samples.

The workflow, including the ambient RNA correction with SoupX, and the thresholds are identical to those applied to the Manual sample, so that the quality metrics of both samples are directly comparable. A fixed random seed was used to ensure reproducibility; it was reset before each stochastic step (rounding of the corrected counts and doublet detection).

Barcode-rank curve

The total number of UMIs was calculated for every barcode. Barcodes were then ranked from the highest to the lowest RNA content to generate a barcode-rank, or knee, plot.

# Calculate the total number of UMIs detected in each barcode
nb_umi_by_barcode <- data.frame(
  barcode = colnames(scmat),
  nb_umi = Matrix::colSums(scmat)
)

# Rank barcodes from the highest to the lowest UMI count
nb_umi_by_barcode <- nb_umi_by_barcode %>%
  arrange(desc(nb_umi)) %>%
  mutate(barcode_rank = seq_len(n()))

# Count the barcodes above the applied UMI threshold and above the Manual knee
n_above_minumi <- sum(nb_umi_by_barcode$nb_umi > minUmi)
n_above_knee <- sum(nb_umi_by_barcode$nb_umi > 3000)

The curve was used as a diagnostic representation of the transition between RNA-rich droplets and the background population. The applied UMI threshold and the knee position identified visually for the Manual sample (3,000 UMIs) are shown as dashed lines.

A total of 4,658 barcodes exceeded the applied threshold of 1,000 UMIs and 2,290 barcodes exceeded 3,000 UMIs, compared with 4,599 cells called by Cell Ranger for this sample.

The transition was not used as a strict automated cell-calling threshold: subsequent filtering was based on the observed gene, UMI and mitochondrial distributions. As the raw matrix was used, the initial gene and UMI filters also acted as an empirical empty-droplet filter. A statistical method such as DropletUtils::emptyDrops() could be used as a complementary sensitivity analysis, but it was not used to define the primary dataset in this workflow.

Ambient RNA correction

Barcodes containing RNA released by lysed cells can carry a background signal that is shared across all droplets. This ambient RNA was estimated and removed with SoupX, using the empty droplets of the raw matrix to define the background profile and the candidate cells (barcodes with at least 200 detected genes) as the cell-containing droplets.

# Define the candidate cells (barcodes with at least 200 detected genes)
cell_barcodes <- colnames(scmat)[Matrix::colSums(scmat > 0) >= 200]
filt_mat <- scmat[, cell_barcodes]

# Initialise the SoupChannel with the raw and the candidate-cell matrices
sc <- SoupChannel(tod = scmat, toc = filt_mat)

SoupX requires a partition of the cells to identify cell-type-specific markers. A temporary clustering of the candidate cells was therefore performed; it was used only for the estimation of the contamination fraction.

Threshold sensitivity

Normalisation

The retained count matrix was normalised using Seurat’s LogNormalize method, as for the Manual sample. For each cell, gene counts were divided by the total cellular count, multiplied by the default scale factor of 10,000 and log-transformed. SCTransform is a possible alternative, but it requires more computational resources since it fits generalised linear models to adjust the residuals.

# Normalise gene expression while preserving the raw counts

  object = sobjFiltrd,
